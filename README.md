# Earnest Tavares - Cybersecurity Portfolio 

This repository hosts my cybersecurity portfolio, documenting practical experience across network security, digital forensics, incident response, and defensive tooling. The site is generated using **Jekyll** and the **Just the Docs** theme for clean navigation and structured documentation.

Background information, professional summary, and ways to reach me. 

### Labs 
Practical exercises using tools such as Snort, Volatility 3, Wireshark, Splunk, RITA, Nmap, and various Linux/Ubuntu utilities.

### Writeups 
Investigation summaries, malware analysis notes, CTF solutions, and incident reports. 

### Projects
Scripts, automation tools, security-focused utilities, and experimentation with home lab setups and related technology.
